# FloatRead 0.1.0 release notes

This is the first open-source preview of FloatRead: a no-backend, BYOK reading companion that stays outside the host page's content and layout.

## Highlights

- Three Chinese reading modes from an explicit text selection.
- Streaming results with cancel, retry, copy, source view and cache.
- OpenAI, OpenAI Compatible, DeepSeek, Anthropic, Gemini and local Ollama adapters.
- Popup/site/global controls, onboarding, context menu and shortcuts.
- Six code-free skins with strict package validation.
- Chinese/English, keyboard, dark environment and reduced-motion support.

## Install

Extract `release/FloatRead-v0.1.0.zip`, then load the extracted directory at `chrome://extensions` using **Load unpacked**. The accompanying `.sha256` and `-files.txt` files are generated by `pnpm package`.

## Verification status

Automated verification results and exact commands are recorded in `PROGRESS.md`. Real Provider smoke tests are tracked independently and are not represented by Mock/adapter tests. Complete the checklist in `MANUAL_TESTING.md` before a Chrome Web Store submission.
