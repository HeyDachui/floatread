# FloatRead 0.4.0 发布说明

0.4.0 把页面翻译从单一精细路线扩展为“快速、智能、精细”三个档位，并加入后台省 Token、其他语言提醒、X/TED/Reddit 页面策略和新的内置宠物动画。

## 用户可见变化

- **智能翻译（推荐）**：正文重视自然表达，菜单和按钮使用简短界面译法。
- **快速翻译**：减少润色、合并更多可见文字，目标是比当前 2–4 秒的精细体验明显更快；真实速度仍受 Provider 和网络影响。
- **精细翻译**：保持原有重视上下文的方式。现有用户迁移后继续使用精细档，新安装默认智能档。
- 页面检测到未选择的语言时，显示“仅本次 / 此网站以后都翻译 / 忽略”；用户选择前不会因为提醒而调用 AI。
- 页面进入后台后不再提交新批次；最多让一个已经提交的批次完成，返回时自动继续。用户主动停止仍然优先，不会自动恢复。
- X、TED 和 Reddit 使用增强的语义识别；普通网页继续使用通用模式。TED 实时字幕、逐字高亮和计时区域不进入页面翻译。
- 内置 Mochi 增加眨眼、拖动行走、转身、点击和五种状态反馈；用户上传的单图宠物保持原有本地去背景与轻量动作。
- Popup 和设置继续只显示输入、输出和总 Token，不估算费用。

## 隐私与边界

- 语言识别在本地已有页面扫描中完成，选择翻译前不上传新增语言文本。
- 页面翻译仍需用户主动开始，刷新后不会自动发起 AI 请求。
- 页面译文直接替换原文节点，不向站点正文内部插入 FloatRead 按钮。
- API Key 不进入 Content Script、页面 DOM、Token 记录、缓存或发布包。

## 安装

解压 `release/FloatRead-v0.4.0.zip`，在 `chrome://extensions` 开启开发者模式并选择“加载已解压的扩展程序”。从旧工作区版本升级时点击一次“重新加载”，然后刷新正在测试的网页。

## 仍需人工观察

- 在真实 X、TED 和 Reddit 页面检查短标题、正文、菜单和动态内容。
- 比较同一页面的快速与精细首段时间、可见区域完成时间和翻译质量。
- 观察 Mochi 在 32px、76px 和 120px 下的眨眼、行走与转身是否自然。
