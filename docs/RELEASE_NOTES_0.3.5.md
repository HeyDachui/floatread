# FloatRead 0.3.5 发布说明

发布日期：2026-07-22

## 本次修复

### 名称旁边的普通词没有翻译

旧规则强调保留产品名、人名和技术名词，模型有时会把包含 `ChatGPT` 的整段文字都当成名称。例如：

`ChatGPT Work => ChatGPT HelpMeWithEverything?`

0.3.5 明确保留真正的专名和 `@账号`，但必须翻译同一段中的普通词、动作和描述。页面 Prompt/cache 版本已经升级，旧缓存中的跳过结果不会继续复用。

### 页面翻译连接频繁断开

Chrome Manifest V3 会回收长期没有扩展消息的后台。仅仅打开连接并不足以持续保活。0.3.5 在真实翻译任务期间每十秒发送一次不含网页文字的轻量心跳；如果后台仍意外重启，网页会自动重连、保留已完成译文并重新提交尚未完成的当前可见文字。重连稳定两秒后才会清零重试次数，避免短时间连续断线形成无限重连。

重连继续使用同一个本地用量记录，已经累计的请求数、缓存命中和 Token 不会清零。用户主动点击停止仍会立即取消当前请求，并且不会自动重启。

## 更新后测试

1. 在 `chrome://extensions` 重新加载 FloatRead，确认版本为 `0.3.5`。
2. 回到 X，单击宠物开始翻译。
3. 检查含 `ChatGPT` 等专名的混合短语：专名保留，普通英文应翻译。
4. 持续使用并滚动页面，短暂后台重启不应再直接显示“连接已断开”；自动恢复失败三次后才会显示错误。
5. 再次单击宠物应立即停止。

本修复没有增加网页读取范围、权限、遥测或开发者服务器。心跳不携带网页文字、模型输出或 API Key。
