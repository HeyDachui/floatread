# FloatRead 0.3.3 发布说明

发布日期：2026-07-22

## 本次修复

我们在实际 X 页面上确认了 0.3.2 的真实提示：`页面翻译连接已断开，请重试。`

原因不是 API Key、语言设置或文本识别，而是手动重新加载开发版扩展时，Chrome 会启动新的翻译核心，却不一定触发“刚安装/刚升级”事件。旧 X 页面上的宠物仍然可见，但已经无法联系新的翻译核心。

0.3.3 改为：每次翻译核心启动时，都检查已经打开的受支持网页。连接正常就保持不动；连接失效才替换旧页面中的 FloatRead 容器。站点范围直接读取当前扩展清单，避免代码与实际权限不一致。

本修复没有改变页面扫描数量、翻译提示词、Provider、缓存、停止行为或凭据策略，也没有增加权限和网络请求。

## 更新后测试

1. 在 `chrome://extensions` 找到 FloatRead，点击“重新加载”，确认版本为 `0.3.3`。
2. 不刷新已经打开的 X 页面，等待约一秒。
3. 单击宠物，应开始翻译可见页面。
4. 再次单击宠物，应立即停止。
5. 若看到 API Key 或 Provider 错误，按页面提示打开设置；这说明页面连接已经恢复，后续是服务配置问题。
