# Pet reference materials

The built-in Mochi asset was informed by nine images supplied for this project as visual and pose references. The reference images are source material only; they are not part of the public repository or release package.

The originals remain outside this repository. Their authorship and redistribution license are not independently verified, so the public package contains only the original FloatRead output or separately cleared assets. See [Mochi asset provenance](MOCHI_ASSET_PROVENANCE.md) for the derived asset and generation description.

Any derived project asset should record which reference set informed it without redistributing the reference files.
