# Maple 与 Piko 内置宠物资产记录

## 最终资产

- `public/pets/maple/{idle,ready,thinking,success,error}.webp`
- `public/pets/piko/{idle,ready,thinking,success,error}.webp`
- 每张均为 512 × 512、RGBA 透明背景、无损 WebP。
- 只在 FloatRead 自己的 Shadow DOM、设置页和 Onboarding 中显示。

## 产生方式

2026-07-23 使用 Codex 内置图片生成工具分别生成 Maple 红熊猫与 Piko 小企鹅的五状态横向角色表。两套角色均从文字描述全新生成，没有使用第三方角色图片作为输入。

共同约束为：同一角色身份和配色保持一致；五格依次为待机、发现内容、翻译中、完成、遇到问题；纯色色键背景；无文字、标识、水印、场景、投影或现有商业角色造型。

Maple 的特征为原创圆润红熊猫、奶油色脸纹、深色四肢、条纹尾巴与蓝色阅读围巾。Piko 的特征为原创圆润小企鹅、炭灰与白色羽毛、珊瑚色喙和脚、薄荷绿色挎包。

生成源先通过项目采用的本地色键工具去除背景，再按五等分区域裁切；同一角色使用统一缩放基准，居中放入 512 × 512 透明画布并保存为无损 WebP。生成源不进入扩展发布包。

首次 Piko 生成请求遇到网络错误，未产生产物；使用相同设计目标重新执行一次后成功。最终只采用复核后的第二次产物。
