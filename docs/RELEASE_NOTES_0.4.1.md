# FloatRead 0.4.1 修复说明

0.4.1 修复用户实测发现的两个精读问题，其他 0.4.0 产品边界保持不变。

## 修复内容

- 页面已经被 FloatRead 翻译后，再选中文字执行“自然中文、看懂重点、解释术语”时，先还原真实原文，再发送给 Background；不再把屏幕上的中文译文当作源文本。
- 精读连接断开时不再无限转圈，改为显示可重试错误；点击重试会建立新连接。
- 即使旧连接已经失效，停止和关闭仍然立即更新本地界面；页面翻译 Stop 也采用同样的先停本地、再尽力通知 Background 的顺序。

## 安装

解压 `release/FloatRead-v0.4.1.zip`，在 `chrome://extensions` 加载解压目录。旧版本用户点击一次“重新加载”，再刷新网页。
