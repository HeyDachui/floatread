# FloatRead 产品讨论记录

更新日期：2026-07-22

本文件只记录产品讨论中的已确认方向、待讨论问题和验证标准。未标记为“已授权实施”的内容不得当作已经完成的功能。

## 已确认方向

### 翻译质量档位

提供三个用户可理解的档位：

1. **智能翻译（推荐）**：正文等重点内容精细翻译；菜单、按钮和普通页面文字快速翻译。
2. **快速翻译**：以尽快看懂为目标，减少等待、请求次数和不必要润色。
3. **精细翻译**：保持目前重视自然表达和上下文的翻译方式，适合学习或认真阅读。

0.4.0 已实现三个档位。一次受控 DeepSeek 小批量测试中，快速档首段 1.398 秒、总计 1.909 秒，精细档首段 1.147 秒、总计 1.683 秒；它证明快速档达到本次低于两秒的体验目标，但也证明单次网络请求无法保证总比精细档快。快速档的确定性优势是每批可合并更多文字、减少长页面的请求轮数；最终仍需在同一真实页面持续滚动对照。

### 宠物表现

0.4.0 的内置 Mochi 已采用分层图片与状态动作结合的路线，具备低频眨眼、拖动行走、方向转身、点击和请求状态反馈，不再只做整体上下浮动或缩放。自动化测试已覆盖状态切换和拖动动作；动作是否自然仍由真实页面人工观察决定。

用户自行上传的单张 PNG/JPG 不要求自动生成上述完整逐帧动作，继续采用单图去背景和适合单图的内置动作反馈即可。内置宠物与用户自定义宠物采用不同质量目标。

### 检测到其他语言

页面检测到用户尚未选择翻译的其他语言时，应提供轻量选择，例如“检测到日语，是否翻译？”。提醒不得自动上传文本，也不应频繁打断用户。

语言识别本身应只复用当前页面扫描中已经得到的结果，不额外调用 AI；只有用户同意翻译后才产生正常翻译请求。因此该提醒功能应是轻量功能，不能为了显示提醒再次遍历整页或影响正在进行的正文翻译。

### 原文和译文

页面翻译默认直接用译文替换原文，不默认使用双语并排或悬停显示原文。

### 平台范围

第一阶段针对三个主流或具有明确学习价值的平台做增强适配：X、TED 和 Reddit。其他普通网站继续使用通用网页能力，不承诺达到平台增强级别。

TED 官方已经为大量演讲提供多语言字幕和交互式文字稿，部分演讲还提供多语言配音，因此 FloatRead 不能宣传“TED 没有翻译”。真实差异是翻译整个学习页面，包括标题、简介、讲者信息、推荐内容和页面操作，而不只翻译演讲内容。参考：[TED 文字稿说明](https://help.ted.com/hc/en-us/articles/360018572954-How-do-I-find-transcripts-for-TED-and-TEDx-talks)与 [TED 字幕说明](https://help.ted.com/hc/en-us/articles/360004232954-How-do-I-activate-subtitles-for-videos-on-TED-com-or-the-TED-app)。

### 用量展示

只显示 Token，不显示费用。记录每次从开启翻译到关闭翻译之间的输入 Token、输出 Token 和总 Token；不评价用户如何使用自己的 Provider，也不提供费用估算。

### 切走页面后的 Token 保护

当前 0.3.5 在用户切换到其他标签页或最小化窗口后不会自动暂停。已经开始的批次会继续完成；如果隐藏页面仍产生新的文字或界面变化，页面观察机制仍可能发起后续翻译，因此当前不能保证切走后不再消耗 Token。页面静止且没有新增文字时不会无缘无故循环请求，关闭标签页则会中止连接和当前任务。

已确认的产品规则是：页面隐藏后不再扫描或提交新批次，最多允许切走前已经提交的一批完成，然后进入“后台暂停”；用户返回页面后，如果此前没有主动点击停止，则自动继续。这样既避免浪费已经提交的请求，也能把离开页面后的 Token 消耗限制在最多一个在途批次。该规则已经进入 0.4.0 代码与自动化测试，真实网站长期观察仍待人工验收。

## 尚待讨论和决定

1. **快速档的长期验收口径**：首段与可见区域完成时间均已记录，但仍要确定公开宣传采用哪些网络条件和 Provider 基准。
2. **语言提醒频率**：0.4.0 已提供仅本次、此网站以后都翻译、忽略三个选择；需观察真实网站是否仍打扰用户。
3. **内置宠物后续动作**：当前使用分层混合动画；是否需要真正逐帧走路以及相应资源大小，取决于人工观感。
4. **Token 展示位置**：Popup 与设置页已有本次会话输入、输出和总 Token；是否需要在悬浮面板增加轻提示仍待决定。
5. **专名处理**：是否允许用户保存常用人名、品牌名和术语的固定译法，避免模型每次选择不同表达。
6. **页面翻译范围**：只处理当前可见区域、滚动时继续处理，还是允许用户主动选择整篇文章；必须避免重新出现页面卡死。
7. **宠物的存在感**：尺寸、停靠位置、动作频率、点击反馈与不遮挡网页内容之间的平衡。

## 当前不变项

- 未主动操作或未获得用户许可时，不上传网页文本。
- 不向正文内部插入按钮，不改变宿主网页布局。
- 用户点击停止后必须真正停止，不能自动恢复翻译。
- API Key 只保存在用户选择的扩展本地或会话存储中。
- 已明确标记为 0.4.0 的能力已经实施；“尚待讨论”部分不代表承诺。
