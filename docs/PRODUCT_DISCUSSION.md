# FloatRead 产品讨论记录

更新日期：2026-07-22

本文件只记录产品讨论中的已确认方向、待讨论问题和验证标准。未标记为“已授权实施”的内容不得当作已经完成的功能。

## 已确认方向

### 翻译质量档位

提供三个用户可理解的档位：

1. **智能翻译（推荐）**：正文等重点内容精细翻译；菜单、按钮和普通页面文字快速翻译。
2. **快速翻译**：以尽快看懂为目标，减少等待、请求次数和不必要润色。
3. **精细翻译**：保持目前重视自然表达和上下文的翻译方式，适合学习或认真阅读。

快速档必须是真的快。产品体验目标是避免超过两秒仍只有转圈：争取约一秒出现第一段有效译文，两秒内让用户开始看到有用结果，剩余内容可以继续渐进显示。该目标需要在真实网络与真实 Provider 下分开测量首段时间和全部完成时间，不能把无法控制的网络延迟伪装成固定保证。

### 宠物表现

当前宠物缺少让用户感知到的动作和互动反馈，现有路线不满足目标。后续需要先讨论并选择新的动画技术路线，再进入开发。不能用简单上下浮动或缩放冒充完整宠物动画。

### 检测到其他语言

页面检测到用户尚未选择翻译的其他语言时，应提供轻量选择，例如“检测到日语，是否翻译？”。提醒不得自动上传文本，也不应频繁打断用户。

## 尚待讨论和决定

1. **快速档的验收口径**：首段出现时间、可见区域完成时间，以及哪些网络条件和 Provider 作为基准。
2. **语言提醒如何避免骚扰**：只问本次、此网站以后都翻译、忽略此语言，是否需要三个选项。
3. **宠物动画路线**：内置宠物采用逐帧动画、部件动画还是混合方案；用户上传单张图片时能实现到什么程度，哪些效果不能虚假承诺。
4. **原文与译文怎么共存**：直接替换、双语显示、悬停查看原文，哪一种作为默认。
5. **平台支持顺序**：通用网页优先，还是先增强 Reddit、Threads、YouTube、微博等具体平台。
6. **费用展示**：是否显示本次开启到关闭的 Token、估算费用、缓存节省量，以及放在什么位置才不打扰阅读。
7. **专名处理**：是否允许用户保存常用人名、品牌名和术语的固定译法，避免模型每次选择不同表达。
8. **页面翻译范围**：只处理当前可见区域、滚动时继续处理，还是允许用户主动选择整篇文章；必须避免重新出现页面卡死。
9. **宠物的存在感**：尺寸、停靠位置、动作频率、点击反馈与不遮挡网页内容之间的平衡。

## 当前不变项

- 未主动操作或未获得用户许可时，不上传网页文本。
- 不向正文内部插入按钮，不改变宿主网页布局。
- 用户点击停止后必须真正停止，不能自动恢复翻译。
- API Key 只保存在用户选择的扩展本地或会话存储中。
- 本轮是产品讨论记录，不代表上述待讨论功能已经实施。
