# FloatRead 0.3.0 发布说明

发布日期：2026-07-22

## 给用户的变化

- 悬浮助手默认从球变成原创宠物 Mochi，默认尺寸 76 px，可在 32–120 px 范围调整。
- 设置中拖入一张 PNG/JPG，即可在本地去浅色背景、裁剪、预览并创建自己的宠物。
- 页面翻译可以选择 1–5 种源语言和 1 种目标语言；扩展按钮和设置界面仍只有简体中文、英文。
- 每次点击开始到再次点击停止，记录输入 Token、输出 Token、总 Token、请求次数和缓存命中；记录只在本机，可清除。
- Popup 只保留总开关、当前网站开关、最近用量、当前皮肤和设置入口。
- DeepSeek 排在 AI 服务首位；普通设置不再显示服务地址、超时和显示名称。服务地址与 30/60/120 秒等待时间在高级设置中。

## 安装

1. 解压 `release/FloatRead-v0.3.0.zip` 到一个固定目录。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择刚才解压且直接包含 `manifest.json` 的目录。
4. 打开 FloatRead 设置，选择 AI 服务和模型，填写 API Key，选择保存方式。
5. 点击“保存”不会联网；点击“保存并测试”会先申请该 AI 服务的精确网站权限，再做一次最小连接检查。

## 安全结果

- Manifest V3；没有 `<all_urls>` 永久权限，没有远程代码。
- Content Script 不读取、接收或保存 API Key。
- 导入宠物图片只在扩展设置页本地处理，最终转成 WebP；不会上传。
- 用量记录不含 API Key、请求正文或模型输出。
- `dist` 与 ZIP 均无源码映射、测试、`.env`、`.secrets`、日志或 `node_modules`。
- 最终秘密扫描通过；临时 `.secrets/FloatRead-APIKEY.txt` 已在真实测试后删除。

## 已知限制

- 自动语言判断是本地启发式，不是完整语言识别模型；很短或多语混合片段可能判断不准。
- 自动去背景针对与图片边缘连通的白色/浅色背景，不承诺处理复杂风景、毛发半透明或深色背景。
- 单张自定义图片使用 FloatRead 内置的形变/位移动作，并不会离线绘制十几张新的角色帧。
- Provider 不返回 Token 用量时，FloatRead 显示“未返回完整 Token 数”，不会编造估算值。
- 本轮自动 E2E 使用本地网页夹具；用户此前已基本通过真实 X 使用测试，但 0.3.0 仍建议按 `MANUAL_TESTING.md` 在登录后的 X 做最终人工回归。
