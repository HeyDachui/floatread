# FloatRead 0.3.2 发布说明

发布日期：2026-07-22

## 本次修复

0.3.1 已经能够启动整页翻译，但启动后的状态反馈不完整：初始提示会自动消失，而后台返回的 API Key、权限、网络、模型或接口错误没有显示在页面上。因此用户看到的是“正在翻译”随后失效，却不知道实际原因。

0.3.2 将页面状态改成持续可见：

- 翻译中显示已完成的文本数量。
- 翻译开启但没有匹配文字时，明确提示检查语言设置或继续滚动。
- Provider 失败时显示真实、已脱敏的原因，并提供“打开设置”按钮。
- API Key 不存在时，明确说明“仅本次会话”或“每次输入”模式可能需要重新输入。
- 错误状态不会再按旧提示的 2.5 秒自动消失。

## 更新后测试

1. 在 `chrome://extensions` 重新加载 FloatRead，确认版本为 `0.3.2`。
2. 回到 X，普通单击宠物。
3. 正常时应持续显示翻译进度，正文逐步变成目标语言。
4. 如果显示“未找到 API Key”，点击“打开设置”，重新输入 Key 并选择“保存并测试”。
5. 如果显示没有符合语言设置的文字，检查设置中的源语言是否包含当前页面语言。
6. 再次单击宠物应立即停止。

本修复没有增加权限、遥测、开发者服务器或自动 AI 请求。错误中不会显示 API Key、Authorization Header、请求正文或模型输出。
