# FloatRead 宠物制作与定制指南

FloatRead 的宠物只显示在扩展自己的悬浮区域中，不会改变网页内容、布局或样式。宠物图片和用户导入的素材都保存在本机浏览器，不会上传到 FloatRead 开发者服务器。

## FloatRead 内置宠物是怎样制作的

目前内置三只原创宠物：Mochi 猫、Maple 红熊猫和 Piko 小企鹅。

Maple 与 Piko 使用“五状态画面 + FloatRead 内置动作”的方式制作：

1. 先确定角色的外形、颜色、表情特征和随身物品。
2. 为同一只角色制作五张画面：
   - 待机：平静陪伴用户。
   - 发现内容：提醒用户已经可以开始操作。
   - 翻译中：表现正在阅读或思考。
   - 完成：表现高兴、跳跃或庆祝。
   - 遇到问题：表现疑惑或担心。
3. 去除每张画面的背景，统一尺寸和角色位置。
4. 转换成轻量透明 WebP，避免明显增加扩展体积。
5. FloatRead 根据实际状态自动切换画面。
6. 点击、拖动行走、左右转身和快速滚动追赶由扩展内置动画负责。

它们不是视频，也不会持续运行复杂的动画程序。只有状态改变或用户操作时才产生相应反馈。

Mochi 采用稍有不同的分层方案：以一张主要角色图为基础，分别控制眼皮、爪子、尾巴和身体，模拟眨眼、挥爪、行走和状态反馈。

## 方法一：一张图片快速制作宠物

这是普通用户最适合使用的方式，不需要编写任何代码。

### 操作方法

1. 打开 FloatRead 设置。
2. 找到“宠物与外观”。
3. 将一张 PNG 或 JPG 拖入宠物制作区域，也可以点击按钮选择图片。
4. 检查自动去除背景后的预览。
5. 如果背景去除不理想，调整“去背景强度”。
6. 输入宠物名称。
7. 点击“使用这个宠物”。

FloatRead 会在本地完成：

- 检查图片类型和大小。
- 缩小过大的图片。
- 去除与图片边缘连通的浅色背景。
- 尽量保留眼白、花纹等被轮廓包围的浅色细节。
- 自动裁掉多余空白。
- 转换成透明 WebP。
- 保存并立即应用宠物。

### 建议使用的图片

- PNG 或 JPG。
- 文件不超过 5 MB。
- 主体清晰、完整，没有被画面边缘截断。
- 背景尽量是白色或单一浅色。
- 角色与背景有明显颜色差异。
- 最好是正方形或接近正方形的图片。
- 不要带文字、水印、复杂阴影或大面积半透明效果。

### 单图宠物可以做什么

单图宠物可以使用 FloatRead 内置的安全动作：

- 低频待机和呼吸。
- 点击反馈。
- 拖动时模拟行走。
- 根据拖动方向左右转身。
- 翻译中的浮动反馈。
- 翻译完成后的弹跳反馈。
- 错误时的摇晃反馈。
- 快速滚动时的追赶反馈。

### 单图宠物的限制

一张静态图片无法自动产生真正的新姿势和表情。FloatRead 不会假装能够仅凭一张图片在本地画出举手、看书、转身或庆祝等新画面。

因此，单图宠物可以移动和反馈，但不同状态仍然使用同一张原始角色图片。如果希望每种状态都有不同表情或动作，需要使用下面的完整宠物方式。

## 方法二：制作五状态完整宠物

完整宠物为五个状态分别准备图片：

```text
我的宠物
├── idle.webp       待机
├── ready.webp      发现内容
├── thinking.webp   翻译中
├── success.webp    完成
├── error.webp      遇到问题
└── skin.json       宠物名称、动作和界面颜色
```

建议五张图遵守以下原则：

- 使用同一只角色，外形、颜色和配饰保持一致。
- 每张图使用相同尺寸，推荐 512 × 512。
- 角色在画面中的大小和站立位置尽量一致。
- 使用透明背景。
- 每张图片不超过 1.5 MB。
- 完整宠物包不超过 5 MB。
- 角色在较小的悬浮尺寸下仍然能够看清。

五张图负责表现真正不同的姿势和表情；FloatRead 仍会在这些画面上增加点击、行走、转身和追赶等轻量反馈。

## 当前高级导入方式

当前版本的一张图制作器已经可以在设置页直接使用。五状态宠物暂时通过 `.floatread-skin` 社区包导入。

高级创作者可以从设置页导出一个现有皮肤包作为结构参考，替换其中的图片和说明文件，再从设置页导入。完整的包结构、字段和限制见[皮肤制作与导入文档](SKINS.md)。

未来计划提供可视化“宠物工坊”，让用户直接拖入一张或五张图片、分别预览每种状态，并一键保存或导出，不再需要手工编辑 JSON。

## 安全边界

宠物包只允许包含：

- JSON 配置。
- PNG 图片。
- WebP 图片。

宠物包禁止包含：

- JavaScript 或其他代码。
- HTML、CSS、SVG 或字体文件。
- 远程图片或网络地址。
- 可执行表达式、事件处理器或外部脚本。
- API Key、Provider 配置、网页内容或翻译缓存。

导入时 FloatRead 会检查文件类型、文件数量、尺寸、总大小、异常压缩、重复路径和路径穿越等风险。宠物图片不会接触或读取用户的 API Key。

## 动画与无障碍

用户可以在设置中关闭内置动画。如果操作系统开启了“减少动态效果”，该系统设置始终优先：宠物仍会切换状态画面，但循环动画、行走、点击和追赶动画会停止。

## 版权建议

公开分享宠物包前，请确认图片是自己创作、明确允许再发布，或拥有合适的开源许可证。不要把宝可梦、迪士尼角色或其他受保护的商业角色直接打包进公开版本。
