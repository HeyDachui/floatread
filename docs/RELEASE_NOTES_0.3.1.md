# FloatRead 0.3.1 发布说明

发布日期：2026-07-22

## 本次修复

- Chrome 重新加载开发版扩展后，已经打开的 X 页面不再留下“看得见但点不动”的旧宠物。新后台会先检查连接，只对失效页面重新注入，并替换旧外壳。
- 宠物普通单击固定为“开始／停止整页翻译”，不会再因为页面上残留选中文字而只打开精读菜单。
- 选中文字后的精读仍然保留：右键宠物可选三种阅读模式，浏览器右键菜单和快捷键也仍可使用。

## 安装或更新

1. 解压 `release/FloatRead-v0.3.1.zip` 到固定目录。
2. 打开 `chrome://extensions`，找到 FloatRead。
3. 首次安装选择“加载已解压的扩展程序”；从旧版更新则选择新解压目录或点击 FloatRead 卡片上的重新加载按钮。
4. 回到已经打开的 X 页面。0.3.1 会主动接管旧页面；若 Chrome 阻止扩展访问该标签页，再手动刷新该 X 页面一次。
5. 普通单击宠物开始整页翻译，再次单击停止。选中文字后需要精读时，右键宠物选择模式。

## 隐私与费用

本修复没有增加权限、开发者服务器、遥测或自动 AI 请求。翻译仍只在用户主动点击后开始；API Key 和用量记录仍按原有本地／会话策略处理。
